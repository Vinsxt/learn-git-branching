# Git Branching

This repository was created to learn and practice Git branching, both locally and remotely.

## What I Learned

* Creating and switching between local branches
* Pushing branches to a remote repository
* Fetching and pulling changes from remote
* Merging branches
* Resolving merge conflicts
* Editing files through the GitHub web editor
* Working with pull requests
